`@dayos/next` permite asignar una URL a cada ventana de tu escritorio, esto te permite
poder renderizar desde el servidor teniendo todos los beneicios de Next, y además poder abrir ventanas desde enlaces normales.


## Inicio rápido

<Steps>

<Step title="Instalación">

```bash
pnpm add @dayos/core @dayos/next
```

</Step>

<Step title="Declara todas tus rutas">

El proveedor necesita la lista completa durante el render, así es como el
servidor sabe a qué ventana pertenece la URL pedida.

```tsx title="app/shell.tsx" added="6,10,12"
"use client";

import { DesktopApp, DesktopIcon, Window, WindowContent } from "@dayos/core";
import { RoutedDesktop, useWindowRoute, WindowRouteProvider } from "@dayos/next";

const ROUTES = ["/", "/about"] as const;

export function Shell({ children }: { children: React.ReactNode }) {
  return (
    <WindowRouteProvider content={children} routes={ROUTES}>
      <RoutedDesktop className="desktop">
        {ROUTES.map((href) => (
          <App href={href} key={href} />
        ))}
      </RoutedDesktop>
    </WindowRouteProvider>
  );
}
```

<Callout>
Entendemos que declarar todas las rutas en un solo sitio puede ser un poco tedioso
y no es la forma más escalable de hacerlo, buscaremos una forma de que no
tengas que hacer esto en un futuro.
</Callout>

</Step>

<Step title="Identifica cada app">

El href de una ventana _es_ su id de `DesktopApp`, de esta forma sincronizamos
la URL con la ventana.

```tsx title="app/shell.tsx" added="3"
function App({ href }: { href: string }) {
  return (
    <DesktopApp id={href}>
      <AppShell href={href} />
    </DesktopApp>
  );
}

function AppShell({ href }: { href: string }) {
  // Este es el contenido de la ventana, no es necesario pasarle ningún parámetro
  // ya que configuramos el id en el DesktopApp correctamente.
  const content = useWindowRoute();

  return (
    <>
      <DesktopIcon>{href}</DesktopIcon>
      <Window keepMounted>
        <WindowContent>{content}</WindowContent>
      </Window>
    </>
  );
}
```

<Callout>
  `useWindowRoute` tiene que ser llamado dentro del contexto de `DesktopApp` para poder acceder al id de la ventana, por eso
  es necesario un nodo hijo para que funcione correctamente.
</Callout>

</Step>

<Step title="Captura el contenido de cada ruta">

Una vez tengas listo tu `Shell`, agregalo a tu layout principal y 
_Next_ junto con _DayOS_ se encargará de renderizar el contenido de cada ruta en la ventana correspondiente.

```tsx title="app/layout.tsx"
import { Shell } from "./shell";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="es">
      <body>
        <Shell>{children}</Shell>
      </body>
    </html>
  );
}
```

</Step>

<Step title="Crea tus páginas">

Usa Next como siempre, no hay nada especial que hacer. Seguimos manteniendo todas 
las ventajas de Next, como la renderización en el servidor y la generación de rutas estáticas.

```tsx title="app/about/page.tsx"
export default async function AboutPage() {
  const data = await getData()

  return (
    <article>
      <h1>Acerca de</h1>
      <p>Esta ventana es una ruta de verdad.</p>
      <span>Se renderizó en el servidor con datos: {data}</span>
    </article>
  );
}
```

</Step>

</Steps>

## Cómo funciona la sincronía

![Diagrama de secuencia: la URL abre su ventana a través del router de Next, @dayos/next y @dayos/core; enfocar o cerrar una ventana actualiza la URL con router.replace](/dayos-next-workflow.svg)

## Ventanas de salida

Al cerrar todas las ventanas de una aplicación, se redirige automaticamente a `/`, 
este comportamiento se puede cambiar con la prop `exitHref` de `RoutedDesktop`.

```tsx
<RoutedDesktop exitHref="/welcome" />
```

Con esto, al cerrar todas las ventanas de la app, se redirige a `/welcome` en lugar de a `/`.

## Ventanas sin ruta

No todas las apps tienen que estar enrutadas. Un `DesktopApp` con un id que no
esta ligada a ninguna ruta o sin un id sigue funcionando como una ventana normal.

```tsx
<RoutedDesktop className="desktop">
  {ROUTES.map((href) => (
    <App href={href} key={href} />
  ))}

  {/* No es una ruta. Abrirla no cambia la URL. */}
  <DesktopApp id="calculator">
    <DesktopIcon>Calculadora</DesktopIcon>
    <Window>
      <WindowContent>
        <Calculator />
      </WindowContent>
    </Window>
  </DesktopApp>
</RoutedDesktop>
```

## Abrir una ventana desde un enlace

No es necesario usar un componente/api especial para abrir una ventana desde un enlace, 
basta con usar el componente `Link` de Next y pasarle la ruta de la ventana que queremos abrir.

```tsx
import Link from "next/link";

<Link href="/about">Acerca de</Link>
```

Además, si quieres que el enlace se vea como un icono de escritorio, puedes usar el componente `DesktopIcon` y pasarle el `Link` como prop `render`.

```tsx
<DesktopIcon render={<Link href={href} />}>
  <DesktopIconText>{title}</DesktopIconText>
</DesktopIcon>
```
