DayOS está dividido en dos paquetes: el núcleo, que contiene toda la funcionalidad, y un adaptador de Next, que añade una URL a cada ventana.
El núcleo es suficiente para un escritorio de una sola página, y el adaptador es opcional.

```bash
pnpm add @dayos/core
```

O con npm o yarn:

```bash
npm install @dayos/core
```

```bash
yarn add @dayos/core
```

## El adaptador de Next

Añade `@dayos/next` para que cada ventana tenga una URL propia y funcione con renderizado en servidor (SSR).

```bash
pnpm add @dayos/next
```

<Callout>
  El adaptador es opcional de verdad: sin él solo pierdes las URL. Un escritorio
  construido solo sobre el núcleo funciona igual, en una sola página.
</Callout>
