DayOS no incluye ninguna hoja de estilos. No hay nada que importar, nada que
sobrescribir y ningún tema contra el que pelear. Lo que sí define es estructural
— un puñado de declaraciones sin las cuales las ventanas no se posicionarían,
recortarían ni desplazarían bien — y todo lo demás es tuyo.

## Qué define DayOS

### Desktop

```css
position: relative;  /* las ventanas se posicionan en absoluto contra él */
overflow: hidden;    /* y él las recorta */
```

### Window

El marco va posicionado en absoluto con un `z-index` que sale de su lugar en la
pila. Dentro, el diálogo es una columna flex:

```css
display: flex;
flex-direction: column;
height: 100%;
```

### WindowContent

```css
flex: 1 1 0%;
min-height: 0;
overflow: auto;
```

Esto es `flex: 1` con `min-height: 0` y deliberadamente no `height: 100%`.
Dentro de una columna flex, el 100% se mide contra la altura completa e ignora
la cabecera, así que el contenido se desborda fuera de la ventana en lugar de
hacer scroll dentro de ella.

### WindowHeader

La cabecera lleva una clase `window-drag-handle`. No es estilo: es el selector
con el que la implementación del arrastre reconoce desde dónde se arrastra la
ventana. Déjala donde está — se fusiona con el `className` que pases, así que
nunca tienes que pensar en ella.

## Pasar tus propios estilos

Todos los componentes aceptan `className` y `style`. La fusión no es un
reemplazo:

- `className` pasa por `clsx` y `tailwind-merge`, así que una utilidad de
  Tailwind tuya gana a la que aportó DayOS en lugar de acabar las dos en la
  lista de clases.
- `style` se fusiona clave a clave, y la tuya gana en caso de colisión.
- Los manejadores de eventos se componen, y el tuyo se ejecuta primero.

<Callout>
  No necesitas Tailwind. `tailwind-merge` solo sabe eliminar duplicados de
  utilidades de Tailwind; con cualquier otro nombre de clase se limita a dejarlo
  pasar.
</Callout>

## Atributos de estado

Las cosas que merece la pena estilar según el estado se exponen como atributos
de datos, para que se puedan apuntar desde CSS sin una sola línea de JavaScript
en tus estilos.

<PropsTable>
  <Prop name="data-interacting" type="Desktop">
    Presente mientras se arrastra o redimensiona cualquier ventana. Su uso
    principal es neutralizar los iframes mientras dura.
  </Prop>
  <Prop name="data-window" type="Window (solo en render de servidor)">
    Marca el marco estático que aparece en el HTML del servidor, antes de que
    haya un escritorio al que entrar por portal.
  </Prop>
  <Prop name="data-maximized" type="Window, WindowHeader">
    Presente mientras la ventana llena el escritorio. Útil para quitar las
    esquinas redondeadas.
  </Prop>
</PropsTable>

```css
.desktop[data-interacting] iframe {
  pointer-events: none;
}

.window-header[data-maximized] {
  border-radius: 0;
}
```

## Con Tailwind

```tsx
<Desktop className="h-dvh bg-slate-900 [&[data-interacting]_iframe]:pointer-events-none">
  <DesktopApp id="notes">
    <DesktopIcon className="flex flex-col items-center gap-1 rounded-lg p-2 text-white hover:bg-white/15">
      <DesktopIconText className="text-xs">Notas</DesktopIconText>
    </DesktopIcon>

    <Window className="overflow-hidden rounded-xl border border-zinc-300 bg-zinc-100 shadow-2xl">
      <WindowHeader className="flex cursor-grab items-center gap-2 border-b border-zinc-300 bg-white px-3 py-2 data-maximized:rounded-none">
        <WindowName className="text-sm font-semibold">Notas</WindowName>
        <WindowActions className="ml-auto flex gap-1">
          <WindowClose className="size-6 rounded-md border border-zinc-300">✕</WindowClose>
        </WindowActions>
      </WindowHeader>
      <WindowContent className="p-4">Hola</WindowContent>
    </Window>
  </DesktopApp>
</Desktop>
```

## Estilos de foco

Los iconos son botones de verdad y las ventanas son enfocables, así que los dos
reciben el anillo de foco del navegador por defecto. Si lo sustituyes,
sustitúyelo de verdad — el escritorio es una superficie que se navega con el
teclado, y un icono cuyo foco es invisible no se puede encontrar.

```css
.icon:focus-visible {
  background: rgb(255 255 255 / 0.15);
  border-color: rgb(255 255 255 / 0.3);
  outline: none;
}
```

## Cursores

Nada te pone un cursor. Los dos que merece la pena añadir son un cursor `grab`
en la cabecera, para que la ventana parezca arrastrable, y un puntero en los
iconos.

```css
.window-header {
  cursor: grab;
}
```

Los cursores de redimensionado de los bordes vienen de las propias asas de
redimensionado y no necesitan nada de ti.
