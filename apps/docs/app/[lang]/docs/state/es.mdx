Qué ventanas están abiertas es una sola lista, que guarda `Desktop`. Si lo dejas
a su aire, se gestiona solo. Si le pasas un valor y un callback, pasa a ser tuya
— que es cómo se persiste, se restaura, o se gobierna el estado de las ventanas
desde un dock o un atajo de teclado.

## Sin control externo

Lo de por defecto. El escritorio mantiene su propia lista, y
`defaultOpenWindows` la inicializa:

```tsx
<Desktop defaultOpenWindows={["notes"]}>
  <App id="notes" />
  <App id="about" />
</Desktop>
```

El orden es el orden de apilado: el último id es la ventana que está delante.

## Controlado

Pasa `openWindows` y `onOpenWindowsChange` y el escritorio deja de guardar
estado. Cada apertura, cierre y cambio de foco pasa por ti:

```tsx
function Workspace() {
  const [openWindows, setOpenWindows] = useState<string[]>([]);

  return (
    <Desktop
      className="desktop"
      onOpenWindowsChange={setOpenWindows}
      openWindows={openWindows}
    >
      <App id="notes" />
      <App id="about" />
    </Desktop>
  );
}
```

<Callout type="warning">
  Controlado significa controlado. Si `onOpenWindowsChange` no desemboca en un
  `openWindows` nuevo, no se abre ni se cierra nada — el botón de cerrar
  parecerá estropeado.
</Callout>

### Persistir una sesión

La lista es un array de cadenas, así que sobrevive a una ida y vuelta por el
almacenamiento sin ninguna ceremonia:

```tsx
const STORAGE_KEY = "workspace";

function Workspace() {
  const [openWindows, setOpenWindows] = useState<string[]>([]);

  // After mount, never during render: the server has no access to storage, and
  // reading it while rendering is a hydration mismatch.
  useEffect(() => {
    const stored = localStorage.getItem(STORAGE_KEY);
    if (stored) setOpenWindows(JSON.parse(stored));
  }, []);

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(openWindows));
  }, [openWindows]);

  return (
    <Desktop onOpenWindowsChange={setOpenWindows} openWindows={openWindows}>
      {/* ... */}
    </Desktop>
  );
}
```

## Por ventana

`DesktopApp` acepta el mismo par para una sola ventana, que a menudo es todo lo
que necesitas:

```tsx
<DesktopApp defaultOpen id="notes">
  {/* se abre al montar, y después se la deja en paz */}
</DesktopApp>
```

```tsx
<DesktopApp
  id="settings"
  onOpenChange={setSettingsOpen}
  open={isSettingsOpen}
>
  {/* se mantiene sincronizada con tu estado, en ambos sentidos */}
</DesktopApp>
```

`onOpenChange` se dispara venga el cambio de donde venga — el icono, el botón de
cerrar, <kbd>Escape</kbd>, una ruta, el botón de otra ventana. Vigila el estado
en lugar de envolver un control concreto, así que no hay ningún camino que se lo
salte.

<Callout title="defaultOpen solo inicializa el cliente">
  Se ejecuta en un efecto, así que una ventana abierta de esta forma no existe
  en el HTML del servidor. Para que una ventana venga abierta desde el servidor,
  ponla en el `defaultOpenWindows` del escritorio — eso es estado del padre, y
  se decide durante el render.
</Callout>

## Gobernar el escritorio desde fuera

`useDesktop` funciona en cualquier punto dentro de `Desktop`, así que los
controles no tienen por qué vivir en una ventana:

```tsx
function Shortcuts() {
  const { openWindow, closeWindow, activeWindowId } = useDesktop();

  useEffect(() => {
    const onKeyDown = (event: KeyboardEvent) => {
      if (event.key === "w" && (event.metaKey || event.ctrlKey)) {
        event.preventDefault();
        if (activeWindowId) closeWindow(activeWindowId);
      }
    };

    document.addEventListener("keydown", onKeyDown);
    return () => document.removeEventListener("keydown", onKeyDown);
  }, [activeWindowId, closeWindow]);

  return null;
}
```

### Las operaciones

- `openWindow(id)` — la abre, o la trae al frente si ya estaba abierta.
- `closeWindow(id)` — la cierra. No hace nada si no estaba abierta.
- `focusWindow(id)` — la trae al frente sin abrirla. Enfocar la ventana que ya
  está delante no cambia nada y no vuelve a renderizar nada.

## Con rutas

`RoutedDesktop` es un escritorio controlado cuyo controlador es la URL, y por
eso no acepta las props de estado de ventanas: las gestiona el proveedor. Lee el
estado con `useDesktop` como siempre, y cámbialo navegando.
