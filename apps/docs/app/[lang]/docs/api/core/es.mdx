Todas las exportaciones de `@dayos/core`. El paquete es de cliente de principio
a fin — su punto de entrada lleva `"use client"` — y tiene React 19 como peer
dependency.

```tsx
import {
  Desktop,
  DesktopApp,
  DesktopIcon,
  DesktopIconText,
  Window,
  WindowAction,
  WindowActions,
  WindowClose,
  WindowContent,
  WindowExpand,
  WindowHeader,
  WindowName,
  useDesktop,
  useDesktopApp,
  useOptionalDesktopApp,
  windowRect,
  type RenderProp,
} from "@dayos/core";
```

## Desktop

El contenedor, y el dueño de qué ventanas están abiertas. Renderiza un `div`.

<PropsTable>
  <Prop name="children" type="React.ReactNode">
    Las apps, y cualquier otra cosa que vaya en el escritorio.
  </Prop>
  <Prop name="wallpaper" type="string">
    Atajo para una imagen de fondo: define backgroundImage, size cover, position
    center y sin repetición. Para un degradado, usa CSS.
  </Prop>
  <Prop name="openWindows" type="string[]">
    Ventanas abiertas de forma controlada, en orden de apilado — la última está
    delante. Pasarla convierte el escritorio en controlado.
  </Prop>
  <Prop name="defaultOpenWindows" type="string[]" default="[]">
    Estado inicial sin control externo. La única forma de tener una ventana
    abierta en el HTML del servidor.
  </Prop>
  <Prop name="onOpenWindowsChange" type="(openWindows: string[]) => void">
    Se dispara en cada apertura, cierre y cambio de foco, venga de donde venga.
  </Prop>
  <Prop name="render" type='RenderProp<React.ComponentProps<"div">>'>
    Reemplaza el `div` que emite este componente, conservando su comportamiento.
  </Prop>
  <Prop name="...props" type='React.ComponentProps<"div">'>
    Todo lo demás se reenvía al `div`. `className` se fusiona, `style` se
    fusiona clave a clave, y los manejadores se componen.
  </Prop>
</PropsTable>

## DesktopApp

Una app: un icono y una ventana unidos por un id. No renderiza ningún elemento
propio.

<PropsTable>
  <Prop name="children" type="React.ReactNode">
    Obligatorio. Normalmente un DesktopIcon y una Window.
  </Prop>
  <Prop name="id" type="string" default="useId()">
    La identidad de la ventana, y con `@dayos/next` también su href. Que dos apps
    compartan un id es un error, que se registra en desarrollo.
  </Prop>
  <Prop name="defaultOpen" type="boolean" default="false">
    Abre la ventana al montar y no vuelve a tocarla. Se ejecuta en un efecto, así
    que no llega al HTML del servidor.
  </Prop>
  <Prop name="open" type="boolean">
    Controlado: mantiene la ventana en sincronía con este valor en ambos
    sentidos.
  </Prop>
  <Prop name="onOpenChange" type="(open: boolean) => void">
    Se dispara venga el cambio de donde venga — un botón, una ruta, un atajo,
    otra ventana.
  </Prop>
</PropsTable>

## Window

El marco. Entra por portal en el escritorio una vez montado; se renderiza en su
sitio, y sin arrastre, cuando todavía no hay nodo de escritorio — el render de
servidor y el de hidratación.

<PropsTable>
  <Prop name="children" type="React.ReactNode">
    Obligatorio. La cabecera y el contenido.
  </Prop>
  <Prop
    name="defaultSize"
    type="{ width: number; height: number }"
    default="70% del escritorio"
  >
    Tamaño inicial en píxeles, acotado al escritorio. Se lee una sola vez, cuando
    la ventana se monta por primera vez.
  </Prop>
  <Prop
    name="defaultPosition"
    type="{ x: number; y: number }"
    default="centrada, en cascada"
  >
    Posición inicial en píxeles. Pasarla saca a la ventana de la cascada.
  </Prop>
  <Prop name="minWidth" type="number" default="240">
    Suelo al redimensionar.
  </Prop>
  <Prop name="minHeight" type="number" default="120">
    Suelo al redimensionar.
  </Prop>
  <Prop name="cascadeOffset" type="number" default="32">
    Píxeles que se desplaza cada ventana sucesiva. La cascada da la vuelta en
    lugar de salirse de la pantalla.
  </Prop>
  <Prop name="keepMounted" type="boolean" default="false">
    Mantiene la ventana en el árbol mientras está cerrada, para que su estado
    sobreviva. Aun así solo se monta la primera vez que se abre.
  </Prop>
  <Prop name="closeOnEscape" type="boolean" default="true">
    Escape cierra la ventana enfocada. Un manejador que llame a
    `preventDefault()` también lo detiene.
  </Prop>
  <Prop
    name="dragCancel"
    type="string"
    default='"button, a, input, select, textarea"'
  >
    Selector de los elementos que no inician un arrastre. Sin él, pulsar un botón
    de la cabecera empezaría además a arrastrar.
  </Prop>
  <Prop name="className" type="string">
    Se aplica al marco.
  </Prop>
  <Prop name="style" type="React.CSSProperties">
    Se fusiona con los estilos de posicionamiento del propio marco.
  </Prop>
</PropsTable>

<Callout>
  `Window` no acepta una prop `render`. El marco es la implementación del
  arrastre y el redimensionado, y cambiarle el elemento por debajo no es algo que
  pueda respetar.
</Callout>

## useDesktop

El estado y los controles del escritorio. Lanza un error fuera de `Desktop`.

```tsx
const {
  desktopEl,        // HTMLDivElement | null — null until mount
  openWindows,      // string[] — stacking order, last is in front
  activeWindowId,   // string | undefined
  openWindow,       // (id: string) => void — opens, or brings to front
  closeWindow,      // (id: string) => void
  focusWindow,      // (id: string) => void — front without opening
  isInteracting,    // boolean — a drag or resize is in progress
  setInteracting,   // (interacting: boolean) => void
} = useDesktop();
```

## useDesktopApp

La app que te contiene. Lanza un error fuera de `DesktopApp`.

```tsx
const {
  id,             // string
  isWindowOpen,   // boolean
  open,           // () => void
  close,          // () => void
  focus,          // () => void
} = useDesktopApp();
```

## useOptionalDesktopApp

Lo mismo, pero devolviendo `null` fuera de un `DesktopApp` en lugar de lanzar un
error. Para componentes compartidos entre contextos con ventana y sin ella.

## windowRect

Dónde va una ventana recién abierta. Pura, y exportada porque es toda la
aritmética de posición inicial que hay — útil si necesitas predecir una posición
en lugar de leerla después.

```tsx
function windowRect(options: {
  desktopWidth: number;
  desktopHeight: number;
  defaultSize?: { width: number; height: number };
  defaultPosition?: { x: number; y: number };
  cascadeStep?: number;    // default 0
  cascadeOffset?: number;  // default 32
}): { x: number; y: number; width: number; height: number };
```

## RenderProp

El tipo de la prop `render`, exportado para envoltorios tuyos que la reenvíen.

```tsx
type RenderProp<P> = React.ReactElement<P>;
```
